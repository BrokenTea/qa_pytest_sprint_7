# Тестирование API для службы доставки самокатов

## Описание проекта

Автоматизированные тесты для REST API сервиса доставки самокатов. Проект включает полное покрытие API для работы с курьерами и заказами, используя моки для изолированного тестирования.

## Технологии и инструменты

- **Python 3.8+** - основной язык программирования
- **Pytest** - фреймворк для написания и выполнения тестов
- **Requests** - для HTTP-запросов к API
- **Allure** - для создания детальных отчетов о тестировании
- **Unittest Mock** - для создания мок-объектов и изоляции тестов
- **POM (Page Object Model)** - паттерн для организации тестового кода

## Тестируемые API-эндпоинты

### Курьеры
- `POST /api/v1/courier` - создание курьера
- `POST /api/v1/courier/login` - логин курьера
- `DELETE /api/v1/courier/{id}` - удаление курьера

### Заказы
- `POST /api/v1/orders` - создание заказа
- `GET /api/v1/orders/track` - получение заказа по треку
- `PUT /api/v1/orders/accept/{id}` - принятие заказа
- `GET /api/v1/orders` - получение списка заказов

## Особенности реализации

### 1. Использование моков
Проект использует библиотеку `unittest.mock` для создания изолированных тестов:
- Мокирование HTTP-ответов сервера
- Тестирование различных сценариев (успешные/ошибочные)
- Изоляция тестов от реального API

### 2. Параметризованные тесты
- Тестирование с разными комбинациями данных
- Проверка граничных значений
- Тесты фильтрации и пагинации

### 3. Allure-отчеты
- Детальная информация о каждом тесте
- Группировка по функциональностям и историям
- Автоматическое добавление описаний и тегов
